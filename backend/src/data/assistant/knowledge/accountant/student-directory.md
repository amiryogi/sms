# Student directory

## Purpose
Look up a student's record, class and contact details.

## Who can use it
Exam officers and accountants (view only). Administrators use **Students** with full editing.

## Where to find it
Left menu → **Students** (`/staff/students`).

## Steps
1. Open **Students**.
2. Type in **Search name, username or admission no…**.
3. Open a row to read the details.

## What you should see
"Student directory (view only)." There are no add, edit or reset buttons.

## Common mistakes
- Trying to add or edit a student: only administrators can.

## Related pages
Collect Fees (accountants), Marks Entry (exam officers).
