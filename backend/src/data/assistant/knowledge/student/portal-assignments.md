# Assignments

## Purpose
See work set by teachers and hand it in (students), or follow it (parents).

## Who can use it
- **Students:** see and hand in their own class's assignments.
- **Parents:** read-only view of each linked child's assignments, what was handed in, marks and
  feedback.

## Where to find it
Left menu → **Assignments** (`/student/assignments` or `/parent/assignments`).

## Steps (students)
1. Open **Assignments**. Tabs: **To do**, **Past due**, **Submitted**, **Graded**.
2. Open an assignment to read the instructions and attachments.
3. Write an **Answer (optional)** and/or attach **Files (optional)** (PDF, Word, images).
4. Click **Submit**. You can hand in only once.

## What you should see
The assignment moves to **Submitted** ("Submitted (marked late)" after the due date). After the
teacher grades it, it shows under **Graded** with marks and feedback.

## Common mistakes
- Submitting with nothing: "Write an answer or attach at least one file."
- Expecting to change a submission: you can hand in only once; ask the teacher.

## Troubleshooting
- An assignment is missing: it is for another class, or the teacher has not set it yet.
- Parents cannot hand in work for the child.
