# Classes and sections

## Purpose
Classes are the grades taught (Kindergarten to Grade 10). Sections are reusable labels (A, B,
Rose, Lotus…) that you attach to a class when enrolling students.

## Who can use it
Administrators.

## Where to find it
Left menu → **Academics** → **Classes** (`/admin/classes`) and **Sections** (`/admin/sections`).

## Steps
**Add a class**
1. **Classes** → **Add class**.
2. Type the **Class name** and the **Grade number**, optionally a **Description**.
3. Save.

**Add a section**
1. **Sections** → **Add section**.
2. Type the **Section name** and optionally the **Capacity**.
3. Save.

## What you should see
The class or section in the list, ready for enrolments, class subjects and teacher assignments.

## Common mistakes
- Creating "Grade 5 A" as a class: create the class "Grade 5" and the section "A" separately.

## Troubleshooting
- A class cannot be deleted while students are enrolled in it.
